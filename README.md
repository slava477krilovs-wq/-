# RemoteHub

RemoteHub — статическая веб-панель на HTML, CSS и JavaScript для организации удалённой работы с компьютерами Windows.

## Что входит в текущую версию

- Обзор устройств и локальные метки компьютеров.
- Инструкция по подключению через Microsoft Quick Assist.
- Раздел передачи файлов с безопасными рекомендациями и ссылкой на OneDrive.
- Настройки интерфейса, светлая/тёмная тема и чек-лист готовности.
- Адаптивный интерфейс для настольных компьютеров и телефонов.

## Важное ограничение

Текущая версия RemoteHub — интерфейс и помощник по настройке, а не самостоятельная система удалённого управления. Браузерная страница на GitHub Pages не может самостоятельно захватывать рабочий стол Windows, передавать нажатия клавиш, управлять мышью или просматривать диски компьютера.

С учётом выбранного режима без установки агента на рабочий ПК RemoteHub открывает официальную инструкцию Microsoft Quick Assist. Для сеанса человек за рабочим компьютером должен ввести одноразовый код и подтвердить демонстрацию экрана/управление. Наличие Quick Assist и возможность его использования зависят от настроек Windows и политик организации.

Передача файлов в этой версии — инструкция, а не прямой файловый канал. Для рабочих документов применяйте только хранилища, разрешённые работодателем.

## Структура

- `index.html` — интерфейс и содержимое страниц.
- `styles.css` — адаптивное оформление.
- `app.js` — навигация, тема, локальные настройки и чек-лист.
- `.github/workflows/pages.yml` — публикация на GitHub Pages.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```powershell
py -m http.server 5500
```

Затем откройте `http://localhost:5500`.

## Публикация

GitHub Pages настроен на публикацию файлов из корня репозитория через GitHub Actions. После успешного запуска workflow сайт будет доступен по адресу, показанному в **Settings → Pages**.

GitHub Pages — статический хостинг и не запускает серверную часть. Не размещайте в репозитории пароли, одноразовые коды подключения, токены или персональные данные компьютеров.

## Что потребуется для полноценного удалённого рабочего стола

Для прямого управления экраном и файловой системой понадобятся разрешённый агент/служба на рабочем ПК либо системная функция удалённого доступа Windows, а также защищённый сетевой канал и серверная авторизация. Не открывайте RDP (TCP 3389) напрямую в публичный интернет.
