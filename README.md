# OmniChat — единое пространство для AI-чатов

Свежий статический HTML/CSS/JavaScript-проект. Не требует сборки, сервера или API-ключей для запуска интерфейса.

## Что умеет

- Единый интерфейс выбора ChatGPT, Claude, Gemini, DeepSeek и Perplexity.
- История диалогов, избранное и экспорт.
- Запрос сохраняется локально в браузере.
- По кнопке открывается официальный сайт выбранного AI-сервиса, а текст запроса копируется в буфер обмена.
- Ответ из внешнего чата можно вручную добавить в историю OmniChat.
- Адаптивная вёрстка для компьютера и телефона.

## Важное ограничение

OmniChat не подключается к внутренним интерфейсам сторонних сайтов и не автоматизирует вход, отправку или чтение ответов. GitHub Pages — статический хостинг, а браузеры ограничивают взаимодействие одной страницы с другой. Кроме того, автоматизация потребительских чатов может противоречить условиям конкретного провайдера. Поэтому пользователь сам вставляет запрос в открывшийся чат и отправляет его, а затем при необходимости добавляет ответ в OmniChat.

История хранится в `localStorage` текущего браузера. Она не синхронизируется между устройствами и не загружается на сервер.

## Запуск локально

1. Распакуй архив.
2. Открой `index.html` в браузере.
3. Для корректной работы буфера обмена рекомендуется запускать сайт через локальный сервер или HTTPS.

Например, если установлен Python:

```powershell
py -m http.server 5500
```

Затем открой `http://localhost:5500`.

## Публикация на GitHub Pages

1. Создай новый **Public** репозиторий на GitHub, например `omnichat`.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `app.js`, `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. После публикации GitHub покажет адрес сайта вида `https://USERNAME.github.io/omnichat/`.
